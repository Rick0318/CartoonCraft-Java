# CartoonCraft Java

This repository contains the Java Edition version of CartoonCraft.

## Included
- Java-compatible texture pack
- Shader pack for Iris / OptiFine
- Fabric animation mod
- Boss Pets mod
- Java-specific generated assets and configuration

## Notes
- This repo intentionally contains only Java Edition content.
- Java shaders and Fabric mods do not work in Bedrock Edition.
- Bedrock content lives in the separate Bedrock repository.

## Requirements
- Minecraft Java 1.21.4
- Fabric Loader 0.16.5+
- Fabric API
- Iris or OptiFine for shader support

## Install
1. Install Fabric Loader
2. Install Fabric API
3. Copy the mod zip files into `.minecraft/mods/`
4. Copy the Java texture pack to `.minecraft/resourcepacks/`
5. Copy the shader zip to `.minecraft/shaderpacks/`

## Important
This repository is Java-only. Bedrock is maintained in `Rick0318/CartoonCraft-Bedrock`.
