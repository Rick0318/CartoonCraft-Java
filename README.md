# CartoonCraft Java
# CartoonCraft Java

This repository contains the Java Edition version of CartoonCraft.
Este repositorio contiene la versión de Java Edition de CartoonCraft.

## Included
## Incluido
- Java-compatible resource pack
- Paquete de recursos compatible con Java
- Shader pack for Iris / OptiFine
- Paquete de shaders para Iris / OptiFine
- Fabric animation mod
- Mod de animación para Fabric
- Boss Pets mod
- Mod de Boss Pets
- Java-only generated assets and build files
- Archivos generados y de compilación solo para Java

## Notes
## Notas
- This project targets Minecraft Java Edition.
- Este proyecto está orientado a Minecraft Java Edition.
- Shader support is only valid in Java Edition.
- El soporte de shaders solo es válido en Java Edition.
- Bedrock is maintained in a separate repository and does not use the same rendering pipeline.
- Bedrock se mantiene en un repositorio separado y no usa el mismo pipeline de renderizado.

## Requirements
## Requisitos
- Minecraft Java 1.21.4
- Fabric Loader 0.16.5+
- Fabric API
- Iris or OptiFine for shader support

## Install
## Instalación
1. Install Fabric Loader
   1. Instala Fabric Loader
2. Install Fabric API
   2. Instala Fabric API
3. Put the mod zip files into `.minecraft/mods/`
   3. Coloca los archivos ZIP del mod en `.minecraft/mods/`
4. Put the Java texture pack into `.minecraft/resourcepacks/`
   4. Coloca el paquete de texturas de Java en `.minecraft/resourcepacks/`
5. Put the shader zip into `.minecraft/shaderpacks/`
   5. Coloca el ZIP del shader en `.minecraft/shaderpacks/`

## Important
## Importante
This repository is Java-only. Bedrock content is maintained in the separate Bedrock repository.
Este repositorio es solo de Java. El contenido de Bedrock se mantiene en el repositorio separado de Bedrock.
